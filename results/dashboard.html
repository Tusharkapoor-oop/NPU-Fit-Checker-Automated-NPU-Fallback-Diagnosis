Root cause and fix
Boundary QuantizeLinear / DequantizeLinear ops adapt FP32 host data to INT8 at the model boundary. The Hexagon NPU cannot execute these in the QDQ wrapper form generated by Qualcomm quantizer.

Fix: Configure compilation with native INT8 input/output tensor types, or move quantization adapters into the host preprocessing pipeline outside the ONNX graph.
